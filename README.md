# 临床工作站 · 绿色便携版

主色精确取自用户提供图片：**#45AF2A**。完整资料随包提供，原始临床内容不改写。

## 医院无网络电脑：直接使用

1. 将整个压缩包复制到电脑或U盘，**完整解压**。
2. 双击最外层的 **“打开临床工作站.html”**。
3. 急症急救直接使用；其他资料点击“解锁资料”，输入 **Yh19990125@**。
4. 无需联网、安装软件、启动服务或事先导入数据库。不要只复制一个网页文件。

只需要电脑已经有支持本应用的浏览器，目标是 Chrome／Edge 第109版及以上。如果系统默认用旧版IE打开，请右键选择兼容的Chrome或Edge。不能保证所有操作系统、浏览器或医院安全策略都允许本地脚本和打印。

可以直接在U盘运行，也可以把整个文件夹复制到另一台兼容电脑。速度取决于U盘、电脑和浏览器；复制到本机硬盘通常更稳定。打印仍需要可用的打印机、驱动和系统打印服务。

## 便携版怎样节省资源

- 不附带或启动 Python、Node.js、服务器、虚拟机或桌面套壳程序。
- 启动只读取约1.4MB的压缩目录，不一次加载约85MB的正文资料。
- 默认按名称、拼音、首字母、症状、主要功效、适应病症等常用字段快速搜索。
- 普通浏览时只在打开详情时读取对应正文，最多暂存两个正文分块。
- 只有主动切换“全文”并点击搜索，才按块扫描完整正文；不在每次输入时反复扫描所有大文件。
- 不将全包再复制一份到浏览器数据库，不改写U盘资料文件。闲置锁定设置尽量保存在当前电脑浏览器，保存失败不影响查阅。
- 缺少原生目录解压能力时自动使用随包备用目录，不需要联网下载程序库。

这些措施减少开销，但浏览器本身、目录解析、搜索和打印仍会使用内存及处理器，不能承诺“零占用”或任意电脑同样快。

## 完整资料

- 急症急救：四本新工作簿，116项，首页免密码。
- 临床医嘱：2,528条，64个原始分类。
- 本院药品：534行，保留药品、疫苗、耗材、器械类别。

151行药品详情缺失、277个病例场景未定、5个混合场景、1个空病程正文以及原有待核对标记均保留，不自动补写。重复和同名不同内容保留独立来源。

## 文件与备份

- 打开临床工作站.html：最外层启动入口。
- dist：完整运行文件与资料，必须保留。
- tools：构建与测试源码，仅开发人员需要，不是运行依赖。
- reports：原文核验、场景映射、缺失、重复、截图及测试证据。
- .github/workflows/pages.yml：GitHub Pages 自动发布配置。

完整复制文件夹就是备份。恢复时重新解压完整包。每次打开默认锁定，急救不受锁影响。界面锁不等于数据加密，源文件和本地浏览器工具仍可读取资料。

## GitHub Pages 网页版

仓库：[ClinicalWorkstation](https://github.com/max9527555-lgtm/ClinicalWorkstation)。

网页模式保留渐进式网页应用和浏览器本地数据库。首次从网站准备需要网络，完成全部资料准备后可断网刷新使用；各电脑和浏览器分别准备。网页版的备份导出／恢复保留。本地文件便携模式直接读取文件夹，采用整文件夹备份，不依赖数据库导入。

发布工作流会检查脚本并发布 dist。仓库必须在“设置 → Pages → 构建和部署 → 来源”选择“GitHub Actions”。发布状态以仓库工作流和实际站点结果为准，不能把提交源码当作发布成功。

仓库是公开仓库，网页资料和源码可公开获取，本地界面密码不构成服务器鉴权。

## 开发重建（使用电脑不需要）

现代开发环境中先按 tools/requirements.txt 安装固定依赖，再依次执行：

    python tools/build_data.py --data-zip "数据源.zip的完整路径" --documents-zip "医疗文书.zip的完整路径"
    python tools/build_portable.py
    node tools/finalize.mjs

然后将 dist/index.html 同步复制为 dist/打开临床工作站.html。构建过程只读原始压缩包，所有转换都作用于派生资料。

自动化测试源码为 tools/test-portable.mjs、tools/test-copy.mjs、tools/functional.mjs。测试运行在开发电脑，不是医院电脑的前置条件。依赖按 pnpm-lock.yaml 固定。

## 单HTML与离线数据包

开发者可运行 `python tools/build_single.py`，从仓库已有资料生成 offline/临床工作站.html 与 offline/临床资料.clinicalpack。普通使用者只需这两个生成文件，用浏览器打开HTML后选择数据包，不需要Python、服务器或GitHub连接。浏览器允许时可保存包，禁止保存时可临时查阅，下次重新选择。

本次首页移除了重复的“临床知识资料”入口行，模块仍可从侧栏访问；网站、PWA与单HTML标识统一为#45AF2A绿色底、白色加号。临床正文未修改。新增单文件导入检查13项、单文件功能回归18项及网页版23项通过，另核验首页入口、图标及五种宽度。专用设计检查器状态为GATE: OFF，未宣称其通过；安卓真机与Win7/109实机未验证。
